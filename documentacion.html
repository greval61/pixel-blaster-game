🎮 Pixel Blaster

ARCADE SHOOTER - Documentación Técnica

Un juego de disparos arcade desarrollado con JavaScript puro y HTML5 Canvas. Cuenta con un sistema de oleadas, múltiples tipos de enemigos, power-ups, efectos de partículas y soporte para dispositivos móviles.

📋 Descripción General

Pixel Blaster es un clásico juego de disparos en formato vertical donde el jugador controla una nave espacial que debe defenderse de oleadas de enemigos. El juego presenta una progresión por oleadas con dificultad creciente, culminando en un jefe final en la oleada 10.

🎮 Controles

  • Mover: Teclas A/D o Flechas Izquierda/Derecha
  • Disparar: Barra espaciadora (automático mientras se presiona)
  • Pausa: Tecla P o ESC
  • Móvil: Touch para mover, botón 🔥 para disparar

🎨 Sistema de Renderizado

El renderizado utiliza HTML5 Canvas con un sistema de sprites generados programáticamente:

🎯 Características

  • Resolución: 480x640 píxeles
  • Sprites generados al vuelo
  • Efectos de neón/glow
  • Fondo con estrellas y nebulosas
  • Sistema de shake para impactos

🌈 Paleta de Colores

  • Neon Cyan - Jugador
  • Explosive Red - Enemigos básicos
  • Phospho Green - Insectos/Escudos
  • Electric Magenta - Fantasmas
  • Laser Yellow - Balas

👤 Sistema del Jugador

La clase Player gestiona todas las características del jugador:

⚡ Estadísticas Base

  • Velocidad: 220 px/s
  • Vidas: 3
  • Cadencia de disparo: 0.15s
  • Invencibilidad tras daño: 2s

🎁 Power-ups

  • Double Shot: Disparo doble (10s)
  • Shield: Escudo protector (8s)
  • Speed: Velocidad +60% (6s)

🔫 Sistema de Disparo

El jugador dispara proyectiles hacia arriba al presionar la barra espaciadora con las siguientes características:

  • Velocidad de proyectil: 400 px/s (hacia arriba)
  • Daño: 1 punto por impacto
  • Color: Neon Cyan (individual), Electric Magenta (doble)
  • Con double shot: 3 proyectiles en patrón abanico
  • Cadencia: 0.15s entre disparos

👾 Sistema de Enemigos

El juego cuenta con múltiples tipos de enemigos, cada uno con comportamientos únicos:

🔴 Drone

  • HP: 1
  • Puntos: 100
  • Velocidad: 60 px/s
  • Patrón: Línea recta
  • Dispara: No

🟢 Insect

  • HP: 2
  • Puntos: 200
  • Velocidad: 45 px/s
  • Patrón: Zigzag
  • Dispara: Sí (cada 2.5s)

🟣 Ghost

  • HP: 1
  • Puntos: 150
  • Velocidad: 50 px/s
  • Patrón: Ondulatorio
  • Dispara: Sí (cada 3s)

👹 Boss

  • HP: 30
  • Puntos: 5000
  • Velocidad: 40 px/s
  • Patrón: Movimiento complejo
  • Dispara: Sí (cada 1.2s + spread)

🧠 IA del Jefe Final

El boss tiene 3 fases de comportamiento que ciclan:

  1. Fase 0: Movimiento horizontal senoidal (3s)
  2. Fase 1: Movimiento rápido horizontal (4s)
  3. Fase 2: Movimiento en amplias ondas (5s)

⏱️ Sistema de Spawning

  • Los enemigos aparecen en formación precalculada
  • Posición inicial aleatoria dentro de una cuadrícula
  • Delay entre spawns disminuye con cada oleada
  • Entre oleadas: 2 segundos de descanso

✨ Sistema de Partículas

El ParticleSystem proporciona efectos visuales con un pool de 500 partículas:

🔥 Tipos de Efectos

  • Engine: Estelas del motor del jugador
  • Trail: Estelas de proyectiles
  • Explosion: Explosiones al destruir enemigos
  • Impact: Impactos de balas

⚙️ Parámetros

  • Velocidad: 20-160 px/s
  • Vida: 0.1-0.9s
  • Tamaño: 1-5px
  • Gravedad: 0-30 px/s²
  • Efecto glow: Configurable

💥 ExplosionEffect

Efecto adicional de onda expansiva con:

  • Flash inicial blanco
  • Círculo expansivo en forma de estrella
  • Duración: 0.4s
  • Radio configurable según tipo de enemigo

🔊 Sistema de Audio

El SoundManager utiliza Web Audio API para generar sonido sintetizado:

🎵 Efectos de Sonido

  • Shoot: Square wave 880Hz
  • Enemy Shoot: Sawtooth 220Hz
  • Explosion: Sawtooth 110Hz
  • Power-up: Double square 660-880Hz
  • Player Hit: Sawtooth 150Hz
  • Boss Defeat: Melodía ascendente

🎶 Música de Fondo

  • Pad sintetizado (sine wave)
  • Frecuencia base: 110Hz
  • Modulación aleatoria: 80-320Hz
  • Volumen dinámico suave
  • Control de mute persistente

🔇 Gestión de Audio

  • Contexto de audio creado tras interacción del usuario
  • Estado de mute guardado en localStorage
  • Master gain para control de volumen global
  • Resumes automático al salir de pausa

🎯 Sistema de Colisiones

El juego utiliza detección de colisiones por rectángulos (AABB):

📐 Tipos de Colisiones

  • Bala vs Enemigo: Daño al enemigo, impacto visual
  • Bala enemiga vs Jugador: Daño al jugador si no está invencible
  • Jugador vs Enemigo: Colisión cuerpo a cuerpo, daño mutuo
  • Jugador vs Power-up: Activación del power-up

🛡️ Sistema de Invencibilidad

  • 2 segundos de invencibilidad tras recibir daño
  • Efecto visual de parpadeo durante invencibilidad
  • El escudo absorbe un daño y proporciona 1s de invencibilidad

🚀 Optimizaciones

El juego implementa varias técnicas de optimización:

💾 Object Pooling

  • Pool de 100 balas
  • Pool de 60 enemigos
  • Pool de 500 partículas
  • Pool de 10 power-ups

🎨 Sprite Caching

  • Sprites generados una vez
  • Canvas offscreen para sprites
  • Reutilización de canvas

⚡ Performance

  • Delta time limiting
  • Filtrado de objetos activos
  • Renderizado condicional
  • Garbage collection minimizada

🎮 Estados del Juego

El juego gestiona cuatro estados principales:

📋 MENU

Pantalla de título con instrucciones y botón de inicio.

🎮 PLAYING

Estado activo donde se ejecuta el game loop completo.

⏸️ PAUSED

Juego detenido, se muestra menú de pausa con opciones.

💀 GAMEOVER

Fin del juego, muestra puntuación final y opción de reiniciar.
